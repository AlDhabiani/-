# 🏝️ سياحة — نظام مكتب سياحة وحجز رحلات

منصة ويب متكاملة (PHP + MySQL) تربط **مكاتب السياحة** بـ **المسافرين** مع إدارة كاملة من **مدير النظام**:
باقات سياحية، حجوزات بحالات متعددة، موافقات، تقييمات، وواجهات عربية احترافية RTL.

---

## ✨ المزايا الرئيسية

| الدور | أبرز الصلاحيات |
|---|---|
| 👑 **المدير** | إدارة المستخدمين، اعتماد مكاتب السياحة (مراجعة هوية + ترخيص)، إدارة الباقات والحجوزات والوجهات، إحصائيات وإيرادات |
| 🏢 **وكيل السياحة** | إضافة/تعديل/حذف باقاته، الموافقة والتأكيد وإلغاء الحجوزات، إحصائيات باقاته، ملف شخصي مع وثائق |
| 👤 **العميل** | بحث وفلترة متقدمة للباقات، حجز ومتابعة الحالة، إلغاء أثناء الانتظار، تقييم الباقات، ملف شخصي |

**نظام الحجوزات** — 5 حالات مع تدقيق انتقالاتها:
`معلق → موافق عليه → مؤكد → مكتمل` (مع إمكانية الإلغاء من أي مرحلة قبل الإكمال).

**أخرى:**
- بحث متقدم (وجهة / نوع / سعر / مدة) + فرز + ترقيم صفحات.
- تقييمات (نجم 1-5) مع متوسط التقييم للباقة.
- رفع صور ووثائق بأمان (تحقق من MIME + حجم + اسم عشوائي).
- صفحة هبوط احترافية (Hero، مميزات، باقات مميزة، إحصائيات، آراء، CTA).
- تصميم متجاوب بالكامل (Bootstrap 5 RTL + خط Cairo + Font Awesome 6).

---

## 🛠️ التقنيات

- **الخادم:** PHP 8 (Core — بدون إطار عمل)
- **قاعدة البيانات:** MySQL / MariaDB (utf8mb4)
- **الواجهة:** HTML + CSS + Bootstrap 5 (RTL) + JavaScript
- **المكتبات:** Font Awesome 6، Google Fonts (Cairo)
- **التوافق:** XAMPP محلياً، InfinityFree (مجانية) في الإنتاج

## 🚀 التثبيت (XAMPP محلياً)

1. ثبّت [XAMPP](https://www.apachefriends.org/) وشغّل Apache و MySQL.
2. انسخ مجلد `travel/` إلى `C:\xampp\htdocs\travel`
3. افتح phpMyAdmin واستورد `travel/database.sql` (ينشئ قاعدة `travel_db` تلقائياً — أو أنشئها أولاً ثم استورد).
4. تأكد أن `db.php` يطابق بياناتك (الافتراضي: `127.0.0.1 / root / فارغ / travel_db`).
5. افتح: **http://localhost/travel/**

### الحسابات الافتراضية للتجربة

| الدور | اسم المستخدم | كلمة المرور |
|---|---|---|
| 👑 مدير | `admin` | `admin123` |
| 🏢 وكيل (صنعاء) | `sanaa_travel` | `agent123` |
| 🏢 وكيل (عدن) | `aden_travel` | `agent123` |
| 👤 عميل | `ahmed` | `client123` |
| 👤 عميل | `fatima` | `client123` |

> ⚠️ **غيّر كلمات المرور فور النشر** من صفحات الملف الشخصي / إدارة المستخدمين.

## ☁️ النشر على InfinityFree

1. أنشئ موقعاً وقاعدة بيانات من لوحة InfinityFree (MySQL).
2. ارفع محتويات مجلد `travel/` إلى `htdocs/` عبر File Manager أو FTP.
3. استورد `database.sql` في phpMyAdmin الخاص بالاستضافة.
4. عدّل `db.php` ببيانات الاستضافة:
   ```php
   $host = "sqlXXX.infinityfree.com";
   $user = "if0XXXXXX_username";
   $pass = "كلمة_السر";
   $db   = "if0XXXXXX_travel_db";
   ```
5. تأكد أن مجلد `uploads/` قابل للكتابة.

## 🔐 الأمان

- **كلمات المرور:** مشفرة بـ `password_hash()` (bcrypt) — لا تُخزن كنص أبداً.
- **حقن SQL:** جميع الاستعلامات عبر **Prepared Statements** (`bind_param`).
- **XSS:** كل إخراج يمر عبر `htmlspecialchars()` (دالة `e()`).
- **CSRF:** رمز جلسة لكل مستخدم يُتحقق منه في كل نموذج POST.
- **الصلاحيات:** كل صفحة محمية (`require_role`) + تحقق ملكية (الوكيل يدير باقاته فقط، العميل حجوزاته فقط).
- **رفع الملفات:** فحص النوع الحقيقي (finfo) + الحد الأقصى للحجم + اسم عشوائي.
- **الجلسات:** `httponly` + `samesite=Lax` + توليد معرّف جديد عند تسجيل الدخول + إنهاء فوري للحسابات الموقوفة.

## 📈 تدفق الحجز

```
العميل يتصفح الباقات ──► صفحة التفاصيل ──► نموذج الحجز (تاريخ + عدد + طلبات)
        │
        ▼  (السعر يُحسب خادماً: سعر الباقة × عدد المسافرين)
   الحجز «معلق»
        │
        ├── العميل يلغي (أثناء التعليق فقط)
        │
        ▼
   الوكيل / المدير يوافق ──► «موافق عليه» ──► «مؤكد» ──► «مكتمل»
        │
        └── أو يُلغى
```
